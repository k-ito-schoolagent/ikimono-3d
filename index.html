シリーズの予定

授業で「ここが動いて見えたら分かる」と思ったものから順につくります。リクエストや「自分でつくります」の宣言は issue へ。

  1. 腎臓のネフロンろ過・再吸収・濃縮。原尿と尿の量と濃度の関係
  2. 昆虫の開放血管系と気管系背脈管と体腔、気門から組織へ直接届く空気。ヒトの閉鎖血管系との比較
  3. ニューロンの活動電位Na⁺ / K⁺ チャネルの開閉と興奮の伝導、跳躍伝導
  4. 筋収縮サルコメアの滑り説。アクチンとミオシン、Ca²⁺ と ATP
  5. 肺のガス交換肺胞と毛細血管、分圧の差による拡散、呼吸運動
  6. 脊椎動物の心臓の比較魚類・両生類・爬虫類・鳥類と哺乳類。心房と心室の数と血液の混ざり方
OPEN SOURCE

みんなでデモを増やしていきましょう。

このラボはオープンソースです。授業で見せたい臓器や生き物の仕組みを、だれでも1ページのデモとして追加できます。GitHub がはじめての方の issue やプルリクエストの練習にも使ってください。

  1. 話してみる「こんなデモがほしい」「この説明はまちがっている」を issue に書く
  2. 直す・足す説明文の改善、モデルの前提の追記、テストの追加をプルリクエストで送る
  3. デモをつくる雛形をコピーして、自分のデモを1ページつくる
参加のしかたを読む issue を書く GitHub のリポジトリ
